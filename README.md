# 単語帳アプリ

ブラウザで動く単語帳＋問題演習アプリ。データはGoogleスプレッドシートに保存され、複数端末（スマホ・PC）で学習記録が共有される。

構成:
- `index.html` — フロントエンド（単一ファイル、外部ライブラリなし）
- `apps-script/Code.gs` — バックエンド（Google Apps Script、スプレッドシートに紐付けて動かす）
- `sample.csv` — 問題データのサンプル

## セットアップ手順

### 1. スプレッドシートとApps Scriptの準備

1. Google スプレッドシートを新規作成する（名前は自由、例: 単語帳DB）
2. メニュー「拡張機能」→「Apps Script」を開く
3. デフォルトで開かれる `コード.gs` の中身を全部消し、`apps-script/Code.gs` の内容を貼り付けて保存
4. 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択で歯車アイコン →「ウェブアプリ」を選択
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」をクリックし、Googleアカウントの権限承認を進める
5. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxx/exec`）をコピーしておく

初回アクセス時にスクリプトが自動で `Questions` / `Records` / `Marks` / `MarkTypes` の4シートを作成する（手動でシートを作る必要はない）。

> スプレッドシートの中身は誰でも編集できる状態ではなく、ウェブアプリ経由のAPIとしてのみ「全員」アクセス可能になる設定。中身を直接見られたくない場合はスプレッドシート自体の共有設定は「自分のみ」のままでOK。

### 2. アプリ本体を公開する

スマホからも使えるように、`index.html` をどこかにホスティングするのがおすすめ（GitHub Pagesが無料で簡単）。

1. GitHubに新しいリポジトリを作成し、`index.html` をpush
2. リポジトリの Settings → Pages → Source で公開ブランチを設定
3. 発行されたURL（`https://<user>.github.io/<repo>/`）をスマホでブックマーク、またはホーム画面に追加

ローカルでファイルを直接開く（ダブルクリック）だけでも動作するが、fetch通信がブラウザによって制限される場合があるため、ホスティングを推奨。

### 3. アプリ側の設定（デッキ登録）

スプレッドシート1つ＝1つの「デッキ」として、アプリに複数登録できる（例: 英語学習用シートと資格試験用シートを両方登録して、ホーム画面で切り替える）。

1. アプリを開き、下部ナビの「設定」タブへ
2. 「デッキ管理」の「新しいデッキを追加」で、デッキ名（自由な名前）と手順1で発行したApps Script URLを入力
3. 「接続テスト」で疎通確認してから「追加」
4. 2つ目以降のデッキも同様に追加すれば、ホーム画面上部のデッキ選択で切り替えられる（学習記録・マーク・CSVインポートは常に「使用中」のデッキ＝スプレッドシートに対して行われる）

### 4. 問題データを入れる

方法は2つ:

**A. CSVインポート（アプリの設定画面から）**

`sample.csv` を参考にCSVを用意し、設定画面の「CSVインポート」からファイルを選択してインポート。

列の意味:
| 列 | 内容 |
|---|---|
| id | 空欄でOK（自動採番される） |
| front | 表面 / 出題文 |
| back | 裏面 / 正解。**複数の正解が必要な問題は `\|` で区切る**（例: `東京\|大阪\|名古屋`） |
| category | 任意。学習範囲の絞り込みに使う |

同じ問題データを単語帳モードでも問題モードでも使う（「type」でモードを固定する列はない）。どのモードで解くかはホーム画面で毎回選ぶ。

**B. スプレッドシートを直接編集**

スプレッドシートの `Questions` シートに直接行を追加してもよい（列構成は上表と同じ）。スマホのGoogleスプレッドシートアプリからでも編集できる。

## 機能

- 同じ問題プールを、**単語帳モード**（表裏フリップ＋マーク付けのみ）と**問題モード**（解答入力＋採点）の両方で学習できる。モードはホーム画面で選ぶだけで、問題データ自体に固定のタイプはない
- **単語帳モード**: カードをタップして表裏フリップ。正誤の記録はせず、マーク付けのみ
- **問題モード**: 解答をテキスト入力して採点。複数正解の問題は完答=○、一部正解=△、不正解=✕として判定・記録
  - 解答欄は `,` または `、` 区切りで複数入力可能
- **マーク機能**: 設定画面で好きな種類のマーク（例: 重要、苦手）を追加でき、学習中に問題ごとにオン/オフを切り替えられる（チェックボックス的な挙動。もう一度押すと解除）
- **範囲フィルタ**: カテゴリ・マークで学習対象を絞り込み
- **出題順**: 順番 / ランダム / 苦手・未学習優先（問題モードでの正答率が低い、または未挑戦のものを優先。単語帳モードでもこの順序を使えるので「問題モードで間違えたものを単語帳で復習する」といった使い方ができる）
- **統計画面**: 解答回数、完答率、判定内訳、マーク集計、正答率が低い問題トップ15
- **複数端末同期**: 学習記録・マークはスプレッドシート経由で共有されるため、スマホとPCで続きから学習できる
- **複数デッキ管理**: スプレッドシート（＝Apps Script URL）を複数登録し、ホーム画面上部でどのデッキを使うか切り替えられる。同じカテゴリ内での絞り込みと違い、データベース自体を完全に分けたい場合はこちらを使う

## 採点ロジックについて

`back` 列を `|` で分割したものを「必要な正解の集合」として扱う。

- 正解が1つ（`|`なし）: 一致すれば○、しなければ✕
- 正解が複数（`|`あり）: 入力された解答（カンマ区切り）のうち、必要な正解が全て含まれていれば○、一部だけ含まれていれば△、1つも含まれていなければ✕

大文字小文字・前後の空白は無視して判定する。

## 既存デプロイの更新方法（type列を廃止したバージョンへの移行）

初期バージョンでは問題ごとに `type`（単語/問題）で固定していたが、単語帳モードと問題モードを同じ問題プールで使えるように変更した。既にデプロイ済みの場合は以下の手順で更新する。

1. スプレッドシートの `Questions` シートのタブを右クリック →「削除」（次回アクセス時に新しい列構成で自動再作成される。サンプルデータ程度ならこれが一番早い。既に入力済みの本番データがある場合は `type` 列だけを手動で削除してもよい）
2. Apps Scriptの編集画面で、`apps-script/Code.gs` の最新内容を貼り直して保存
3. 「デプロイ」→「デプロイを管理」→ 既存デプロイの鉛筆アイコン →「バージョン: 新バージョン」を選んで「デプロイ」（URLは変わらないので、アプリ側の設定を変更する必要はない）
4. CSVを入れ直す場合は新しい`sample.csv`（type列なし）を使う

さらに、マークをオン/オフのトグル方式に変更したバージョンに更新する場合は、古い挙動（クリックのたびに行が増える）で溜まった重複行が`Marks`シートに残っていると、1回のクリックで消えきらずオンのまま見えることがある。気になる場合は`Marks`シートの中身（ヘッダー行以外）を一度全部削除してから使うとクリーンな状態になる。
