# 単語帳アプリ

ブラウザで動く単語帳＋問題演習アプリ。同じ問題データを、単語帳モード（表裏フリップ）と問題モード（解答入力＋採点）の両方で使い分けられる。

学習記録（正誤・マーク）はあなた自身のGoogleスプレッドシートに保存される。他の人と同じアプリを使っても、データが混ざることはない。

## アプリを開く

**[https://kiyokikakene.github.io/flashcard_app/](https://kiyokikakene.github.io/flashcard_app/)**

スマホでこのURLを開いてホーム画面に追加しておくと使いやすい。

自分専用のデータを持つには、最初に一度だけ「自分のGoogleアカウントに保存先を作る」作業が必要（難しくはない、5分程度）。

## セットアップ

### 1. 自分用のデータ保存先を作る

1. Google スプレッドシートを新規作成する（名前は自由、例: 単語帳DB）
2. メニュー「拡張機能」→「Apps Script」を開く
3. デフォルトで開かれるコードの中身を全部消して、[このコード](https://raw.githubusercontent.com/kiyokikakene/flashcard_app/main/apps-script/Code.gs)の内容を丸ごとコピーして貼り付け、保存
4. 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択で歯車アイコン →「ウェブアプリ」を選択
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」をクリックし、Googleアカウントの権限承認を進める
     - 「このアプリは Google で確認されていません」という警告が出たら「詳細」→「（プロジェクト名）に移動」→「許可」でOK（自分で作ったスクリプトなので問題ない）
5. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxx/exec`）をコピーしておく

初回アクセス時に必要なシートが自動で作られる（手動でシートを作る必要はない）。

### 2. アプリにデッキとして登録する

1. [アプリ](https://kiyokikakene.github.io/flashcard_app/)を開き、下部ナビの「設定」タブへ
2. 「デッキ管理」の「新しいデッキを追加」で、好きなデッキ名（例: 自分の単語帳）と、手順1で発行したURLを入力
3. 「接続テスト」で疎通確認してから「追加」

これでホーム画面から学習を始められる。

### 3. 問題データを入れる

方法は2つ。

**A. CSVインポート（アプリの設定画面から）**

[サンプルCSV](https://raw.githubusercontent.com/kiyokikakene/flashcard_app/main/sample.csv)を参考にCSVを用意し、設定画面の「CSVインポート」からファイルを選択してインポート。

列の意味:
| 列 | 内容 |
|---|---|
| id | 空欄でOK（自動採番される） |
| front | 表面 / 出題文 |
| back | 裏面 / 正解。**複数の正解が必要な問題は `\|` で区切る**（例: `東京\|大阪\|名古屋`）。**表記ゆれで許容したい別解は `/` で区切る**（例: `東京/とうきょう/トウキョウ`。どれを入力しても正解扱い） |
| category | 任意。学習範囲の絞り込みに使う |
| note | 任意。例文・解説・補足など。単語帳モードは裏面を開いた時、問題モードは採点後に表示される |

同じ問題データを単語帳モードでも問題モードでも使う。どのモードで解くかはホーム画面で毎回選ぶ。

**B. スプレッドシートを直接編集**

自分のスプレッドシートの `Questions` シートに直接行を追加してもよい（列構成は上表と同じ）。スマホのGoogleスプレッドシートアプリからでも編集できる。

## 機能

- 同じ問題プールを、**単語帳モード**（表裏フリップ＋マーク付けのみ）と**問題モード**（解答入力＋採点）の両方で学習できる
- **単語帳モード**: カードをタップして表裏フリップ。正誤の記録はせず、マーク付けのみ
- **問題モード**: 解答をテキスト入力して採点。複数正解の問題は完答=○、一部正解=△、不正解=✕として判定・記録
  - 解答欄は `,` または `、` 区切りで複数入力可能
- **例文・解説**: 問題ごとに`note`列で補足情報を登録でき、単語帳モードは裏面を開いた時、問題モードは採点後に表示される
- **マーク機能**: 好きな種類のマーク（例: 重要、苦手）を追加でき、問題ごとにオン/オフを切り替えられる（チェックボックス的な挙動）
- **範囲フィルタ**: カテゴリ・マークで学習対象を絞り込み
- **出題順**: 順番 / ランダム / 苦手・未学習優先
- **統計画面**: 解答回数、完答率、判定内訳、マーク集計、正答率が低い問題トップ15
- **複数端末同期**: スマホとPCで同じデッキを登録すれば、続きから学習できる
- **複数デッキ管理**: 用途別にスプレッドシートを複数登録し、ホーム画面で切り替えられる

## 採点ロジックについて

`back` 列を `|` で分割したものを「必要な正解の集合」として扱う。さらに各要素を `/` で分割したものは「そのマスの別解（どれか1つ合っていればOK）」として扱う。

- 正解が1つ（`|`なし）: 一致すれば○、しなければ✕
- 正解が複数（`|`あり）: 入力された解答（カンマ区切り）のうち、必要な正解が全て含まれていれば○、一部だけ含まれていれば△、1つも含まれていなければ✕
- 別解（`/`あり）: 例えば `東京/とうきょう` なら、`東京`でも`とうきょう`でもそのマスは正解扱い。`東京/とうきょう|大阪/おおさか` のように `|` の複数正解問題と組み合わせ可能

大文字小文字・前後の空白・ひらがな/カタカナの違いは無視して判定する（例: 「とうきょう」と「トウキョウ」は同一視）。読み方が複数ある漢字（例:「一行」など）は自動判定できないので、表記ゆれしやすい問題は`back`列に`/`で別解を明示登録するのがおすすめ。
